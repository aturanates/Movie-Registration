# 🎬 Movie Registration System

A simple yet functional Windows Forms application for managing movie and category records, built using the Entity Framework Code First approach.

## 🚀 Features

- Category Management: List, add, update, and delete categories  
- Movie Management: List, add, update, and delete movies  
- Modern UI: Flat design for a clean and user-friendly interface  
- Code First: Database operations handled via Entity Framework Code First  
- Relational Data Model: One-to-many relationship between categories and movies  

## 🛠️ Technologies Used

- .NET Framework 4.7.2  
- Entity Framework 6.4.4  
- Windows Forms  
- SQL Server
